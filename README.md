## 关于正版

本书为个人学习用途的非营利翻译，不替代原版。如果你觉得这本书对你有帮助，请购买正版支持作者和出版社。

**Lodish *Molecular Cell Biology* 第 8 版目前没有官方简体中文翻译版**，建议购买英文原版：

- 📘 [Amazon: Molecular Cell Biology, 8th Edition](https://www.amazon.com/Molecular-Cell-Biology-Harvey-Lodish/dp/1464183392) — ISBN 978-1464183393
- 📘 [Macmillan Learning 官方页面](https://www.macmillanlearning.com/college/us/product/Molecular-Cell-Biology/p/1464183392)

> 该书已被翻译为十二种语言。日本东京化学同人出版了日文版《分子細胞生物学 第8版》（2019）。台湾藝軒出版社曾出版过早期版本的繁体中文译本《分子細胞生物學》（约 2005 年），但基于的是较早版本，非第 8 版。

如果你更喜欢读中文版细胞生物学教材，可以考虑以下替代（均为不同作者）：

- **《细胞的分子生物学》**（*Molecular Biology of the Cell*, Alberts 等著）— 科学出版社有官方中文译本
- **《细胞生物学精要》**（*Essential Cell Biology*, Alberts 等著）— 科学出版社有官方中文译本
